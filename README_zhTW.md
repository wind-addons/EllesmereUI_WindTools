## 🧬 Fork from ElvUI_WindTools

**EllesmereUI_WindTools** 是 [ElvUI_WindTools](https://github.com/wind-addons/ElvUI_WindTools) 的遷移分支,將 WindTools 從 **ElvUI** 移植到 **EllesmereUI**。

- 原專案:[wind-addons/ElvUI_WindTools](https://github.com/wind-addons/ElvUI_WindTools)
- 依賴:需要先安裝 **EllesmereUI**
- 已內建獨立的 WindTools 選項面板;目前僅以下模組完成遷移。
